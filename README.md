# Suivi du matériel

Page HTML autonome pour suivre une liste d'outillage : on l'a ou non, remises (date, quantité, à qui), commentaire.
Données enregistrées dans le navigateur ; sauvegarde/restauration en JSON, export CSV pour Excel.

Utilisation : ouvrir `index.html`, ou `python3 -m http.server 8080`.
